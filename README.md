# Pós-Graduação Fanese

Site estático da Pós-Graduação Fanese, construído com Astro para publicação na Hostinger.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Publicação

```bash
npm run build
```

Envie o conteúdo da pasta `dist/` para a pasta do subdomínio `pos.fanese.edu.br` na Hostinger.
